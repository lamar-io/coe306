# COE 306 – Introduction to Embedded Systems
### Complete Study Guide | KFUPM

A comprehensive study website for COE 306 covering all lecture material, past quiz questions, conceptual MCQs, and interactive practice tools.

## Contents

- **Chapter 1** — Embedded Systems (definitions, platforms, design process, real-time)
- **Chapter 2** — Instruction Sets (ARM, PIC16F, VLIW/Superscalar)
- **Chapter 3** — CPUs (I/O, interrupts, cache, memory management, power)
- **Chapter 4** — Computing Platforms (DMA, bus architectures, memory types, debugging)
- **Chapter 5** — Program Design (FSMs, circular buffers, timers, ISR vs polling)
- **Chapter 6** — ADC (sampling, quantization, SAR, Flash, Half-Flash)
- **Chapter 7** — PWM (LPC timer, duty cycle, single-edge, double-edge)
- **Chapter 8** — Serial Communication (UART, SPI, I²C, baud rate)

## Features

- Full lecture-based summary for all 8 chapters
- Past quiz questions from Terms 161, 171, 181, 191, 252
- Interactive MCQs with scoring
- Written questions with full solutions
- Fill-in-the-blank and numeric questions with answer checking and reset
- Interactive widgets: SAR ADC stepper, PWM visualizer, FSM simulator, UART frame builder, circular buffer, bus/ADC calculators
